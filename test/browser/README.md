# 大 JSON 浏览器回归

在仓库根目录执行 `python3 -m http.server 8767 --bind 127.0.0.1`，在 Chrome 打开：

`http://127.0.0.1:8767/test/browser/json-format-performance.html`

选择本地 JSON 文件，或点击“载入生成数据”，然后运行 30 轮。2 倍、5 倍数据基于最后载入的样例生成。页面直接加载生产 Formatter、CodeMirror 和样式，验证完整文本、子折叠保留、重复折叠与全部展开，并记录首帧时间和长任务。可直接点击渲染区的箭头、省略号、复制和下载进行人工验收。

“载入原始样例”用于本机自动验收服务器的 `/sample` 路由；普通静态服务器下使用文件选择即可。原始文件不入库。

HTTP 页面仅补充验证渲染性能。扩展下载 API、CSP 和系统剪贴板仍需在实际加载的扩展中验收，不能用此页面替代。

2026-10-15 本机 Chrome 验收：加载最终 `output-chrome/apps` 里的压缩脚本，使用 `response_new.json`（54,545 行、2,796,387 字符）连续 30 轮。根节点、最大子节点、全部展开首帧 P95 分别约 40、44、31ms，测量窗口最长任务 85ms；重新折叠后的标记数量保持一致，手动折叠的缓存视图可正确清理，末尾行可见。真实复制事件包含完整文本，下载文件逐字符一致。时间含浏览器布局，仍依赖设备和浏览器状态。

渲染器稳定保留折叠、展开两份只读 Doc，以减少重复分配和垃圾回收；更换输入时释放缓存。测试中的 DOM/VM doubles 只验证行为，以上时序来自真实组件页面。

5 倍样例额外运行 5 轮（272,727 行、15,072,847 字符）：同样通过全文、折叠标记及末尾可见性检查，全部展开最高约 137ms；测量窗口有一次 266ms 长任务。这个放大用例不代表任意大小文件都能保持 100ms 以内。

2 倍样例额外运行 5 轮（109,092 行），同样通过全部断言，全部展开最高约 82ms，测量窗口最长任务 185ms。
