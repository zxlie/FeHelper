FeHelper curl 转 Python requests

粘贴 curl 命令，生成可复制的 Python requests 代码。转换过程不会执行命令或发送请求。

支持范围与使用说明

支持 POSIX/Bash 引号、续行、-X、-H、-d、--data-raw、--data-binary、--data-urlencode、--json、-G、-I、-u、-b、-A、-e、-L、-k，以及文本 -F 表单。仅支持单个 HTTP(S) URL；文件上传、变量、PowerShell/cmd 语法、--compressed、超时和未知选项会报错。输出适用于 Python 3 + requests，运行前请核对凭据及请求内容。
